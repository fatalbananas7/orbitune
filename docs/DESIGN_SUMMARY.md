# Design Summary
**Hook:** a one-touch orbital slingshot where every catch is a musical note — your play composes the soundtrack.
**Core loop:** orbit → release/aim → fly → catch (note, points, fuel) every 1–3 s; runs last 30–180 s as fuel drain accelerates.
**Addictive systems:** perfect catches (hit-stop + chime), chords, combo multiplier with hesitation timer, Overdrive music swell, prism-star variable loot, sector banners every 18 catches, best-height line in-world, missions, ranks, daily seed & streak, upgrade/trail unlock teaser on every results screen, instant AGAIN.
